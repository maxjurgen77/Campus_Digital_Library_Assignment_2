# ASSIGNMENT TWO REPORT
## Library Management System

### 1. Introduction

This project involves the development of a Library Management System using Python. The system is designed to help manage library activities, including adding books, registering patrons, borrowing and returning books, searching for titles, and saving or loading records. The project builds on the work completed in Assignment One and introduces additional programming concepts.

### 2. Objectives

The main objectives of this assignment are:

- To update the problem statement from Assignment One.
- To implement three forms of polymorphism.
- To apply exception handling to manage errors.
- To save and read information from files.
- To use an Abstract Data Type (ADT), such as a list.
- To develop a graphical user interface with menus, buttons, and other components.

### 3. System Description

The Library Management System provides a graphical interface through which users can perform basic library operations. Users can add books, register library patrons, borrow and return books, and search for available titles. The system also supports saving records to files and loading previously saved information.

### 4. Implementation of Programming Concepts

The system applies object-oriented programming principles, including classes, objects, inheritance, and polymorphism. Three forms of polymorphism are incorporated to demonstrate different ways in which methods and objects can behave.

Exception handling is used to manage errors that may occur during operations, such as invalid input or problems when accessing files. File handling allows the system to store information for future use. A list is used as an Abstract Data Type to organise and manage library records.

### 5. Graphical User Interface

The graphical user interface provides a convenient way to interact with the system. It includes functions for adding books, registering patrons, borrowing and returning items, searching for titles, and saving or loading records.

### 6. Testing

The system should be tested to confirm that its main functions work correctly. Testing includes adding books, registering patrons, borrowing and returning books, searching for titles, handling invalid input, and saving and loading records. The results of these tests should be recorded after the functions have been executed.

### 7. Conclusion

The Library Management System demonstrates the application of object-oriented programming and other programming concepts in developing a practical application. The project combines a graphical user interface, polymorphism, exception handling, file operations, and an Abstract Data Type to support basic library management activities.
